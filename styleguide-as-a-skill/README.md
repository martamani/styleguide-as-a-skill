# Pottery AI Content Pipeline

A case study of an AI content system I built on my pottery pieces: content generation, GEO/schema optimization, editorial QA, and
lead-routing automation.

The pipeline runs in AirOps and Make.com; this repo has the write-up
and the content it produced.

**Read the case study:** https://martamani.github.io/pottery-ai-content-pipeline/

## What's here
- `case-study.md` / `system-architecture.html` — how the system was designed
- `editorial-guidelines.md` — the brand-voice rules the pipeline applies
- `pieces.md`, `process.md`, `faq.md`, `care-instructions/` — content the system generated based on those rules
- `repurposed-content.md` — the same content adapted for other channels
- `photos/` — screenshots (e.g. the Make.com scenario)

**Built with:** Claude, AirOps, Tally, Make.com
